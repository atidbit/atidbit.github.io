Number Check

Static GitHub Pages tool. Shows prefix / rate-center style info, FCC spam complaints, and links to name lookup sites. It cannot privately identify a person without a paid API.

US/Canada 10-digit numbers work best. Optional AbstractAPI key below unlocks live carrier + line type.

Optional: AbstractAPI key (carrier / line type)

Free tier is typically 100 lookups/month. Key is stored only in this browser (localStorage). Never commit a key to GitHub.

Data sources: public NANPA-style prefix knowledge, FCC Consumer Complaint Data (opendata.fcc.gov), optional Abstract Phone Validation API. Name/address results on Whitepages / Truecaller / Spokeo are those companies’ products — this page only links out.
